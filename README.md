## About
This project intends to aid in the computational analysis of Somali poetry and includes two main features:
- rule based syllabification 
- metrical scansion 
 
The scope of this project is also restricted to standard, Af Maxaa dialect, Somali.

## How to Use
Upto three command line arguments can be supplied for syll.py.


If one or two files are supplied, then the first will always be taken as the input file,

And the second will be taken as a combined syllable and meter output file.
```
python3 syll.py input.txt
```
```
python3 syll.py input.txt output.txt
```
If, and only if, three files are supplied,

The first isupdated readme to reflect new io output options taken as the input,

The second is taken as the syllabification output file,

And the third is taken as the metrical scansion output file.
```
python3 syll.py input.txt syllable.txt meter.txt
```
If no command line arguments are given the following prompt is shown.

```
python3 syll.py 
Enter one line:
```
The program will then return the syllabified line along with it's meter.

# Outline of Probabilistic Approach

## Probablistic Diphthong Scanning

```
Enter one line: soomaali baan ahay

['soo', 'maa', 'li', 'baan', 'a', 'hay']
[2, 2, 1, 2, 1, '1']
```
Previously diphthongs were scanned as '?', now through an assessment of diphthong frequencies for jiifto poetry diphthongs are corrected by assessing the maximum likelihood that the given line of poetry fits known jiifto templates. Other genres of poetry will be assessed at a later date.

## In Concrete Terms:

Let a syllabified poetic line be given as a sequence of `n` syllables (including word boundary tokens `SP`), denoted **x** = (x₁, ..., xₙ). The model predicts the corresponding metrical label sequence **y** = (y₁, ..., yₙ), where each `yᵢ ∈ {1, 2}` encodes moraic weight (1 = short / S, 2 = long / L).

Due to phonological ambiguity (e.g., volatile diphthongs such as "ay", "aw"), the front-end syllable analyzer may output *partially observed* labels:



`yᵢᵒᵇˢ` =
{
1 if syllable unambiguously short,
2 if syllable unambiguously long,
? if moraic weight uncertain
}


Let `U = { i | yᵢᵒᵇˢ = ? }` denote the set of unknown positions.

The model assumes that valid metrical lines are generated by drawing from a finite, ranked set of canonical templates `T = { t^(1), ..., t^(K) }`, where each `t^(k) ∈ {1,2}ᵐₖ`. Template frequencies, derived from the annotated corpus (see Table 1), induce a categorical prior:



`t ∼ Cat(π)`,
`πₖ = cₖ / Σₖ cⱼ`,


where `cₖ` is the count of lines matching template **t**^(k) in the training data.

Conditional on `t = t^(k)`, the observed label sequence `yᵒᵇˢ` must be *compatible* with `t^(k)`, i.e., `|t^(k)| = n` and for all `i ∉ U`, `yᵢᵒᵇˢ = tᵢᵏ`.

The posterior over templates is thus:



`P(t = t^(k) | yᵒᵇˢ, x) ∝
{
πₖ if t^(k) is compatible, otherwise
0.
}`


---

### Assumptions of the Model

The model makes the following key assumptions:

- Valid meter is fully covered by enumerated templates (no out-of-vocabulary patterns).
- Template selection is independent of syllabic features beyond compatibility.
- Missing morae (`yᵢ = ?`) are *missing completely at random* (MCAR) — a simplification that ignores phonological context (e.g., coda consonants, stress attraction).

---

### Estimation Objective and Algorithm

We perform **Maximum A Posteriori (MAP)** estimation:



`ŷ = argmaxₖ ∈ T { πₖ · I[ t^(k) is compatible with yᵒᵇˢ ] }`


This yields a *deterministic, greedy search* over **T** in descending order of πₖ (i.e., empirical frequency rank). If no compatible template exists (e.g., conflicting known morae or novel line length), we resolve unknowns via fallback sampling (which, for us, means random sampling). The algorithm runs in **O(Kn)** time per line, where `K = 35` templates and `n ≤ 9` syllables per line — effectively constant-time.

This approach follows the Bayesian decision framework under 0–1 loss (Murphy, 2012, §5.7), where optimal decisions minimize expected misclassification error.
